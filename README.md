# TRANS – Transgender Support Platform

An Android application that helps transgender individuals access essential services in one place.

## Features
- **Hospital booking** – find hospitals and book appointments
- **Restroom locator** – locate nearby restrooms
- **Counseling** – access counseling support
- **Transport** – transport services

## Tech Stack
- Java
- Android Studio
- XML (UI layouts)
- XAMPP (local server)
- MySQL (database)

## Setup
1. Clone the repository.
2. Open the project in Android Studio and let Gradle sync.
3. Start Apache and MySQL in XAMPP, then import the database file.
4. Update the server URL in the app to your local IP address.
5. Run the app on an emulator or Android device.
